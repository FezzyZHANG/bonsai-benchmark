# Hidden test data

- `corpus.txt` — hidden corpus used for logits, position and greedy cases. It
  is an excerpt (chapters II onward, 140,000 characters) from *Pride and
  Prejudice* by Jane Austen, Project Gutenberg ebook #1342 (public domain). It
  is deliberately different from the visible `data/samples/` corpus.
- `tokenizer_cases.json` — hidden tokenizer strings (Unicode, combining marks,
  code, whitespace, special tokens).
- `golden/` — generated by `verification/tools/generate_golden.py` with the
  CPU-only oracle (`verification/bin/bonsai-ref-cpu`, no Vulkan backend) and
  the safetensors file for dequant checks. Gitignored; regenerate with
  `verification/verify.py` or the generator directly.

The golden format is a `manifest.json` plus raw little-endian float32 logits
files and `.npy` dequant tensors. Token ids in the manifest come from the
oracle tokenizer; the verifier's harness compares a submission against the CPU
golden, matching the CPU-vs-Vulkan agreement methodology.
